# Project Title: PokemonStairs
This is the repository for my first game made with Claude, PokemonStairs

# Project Background
I love Pokémon GO game collecting pokemon. I also love stair-climbing game. I used to make games on Scratch. I learned from my dad and YouTube videos. Last week, my mom taught me how to use Claude.

# System Overview
I told Claude my story. In my game, my favorite Pokémon climb stairs, find eggs, and grow into new forms. Claude did a great job making my ideas real. But sometimes it drew the wrong Pokémon or made strange backgrounds. So I kept talking to Claude, and I tried to explain my ideas clearly. That is how I made this game.

# Development Episode
The hardest part was testing. In my game, you get an egg after 350 steps. But the egg does not always have a Pokémon inside. Climbing 350 steps was really hard! When I finally opened my egg, it was empty! Dad said, "Let's make it easier just for testing." But I am a developer, so I wanted to do it the real way. I kept playing again and again. In the end, it was just too tiring, so I had to accept my dad's idea.

# How to play
The game has only two buttons. One button climbs, and the other button turns. If you step the wrong way, you fall. The game works in your web browser, so you don't need to download anything or be online.
